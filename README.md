# Smart Cane — AI 스마트 지팡이

시각장애인을 위한 라즈베리파이 기반 보행 보조기기입니다. 지팡이에 달린 카메라가 본 장면을 한국어 음성으로 설명합니다.

버튼을 **한 번** 누르면 전방 위험을 한 문장으로 경고하고, **두 번** 누르면 주변 상황을 세 문장으로 묘사합니다.

> USG 공유대학 캡스톤 종합설계 경진대회 **우수상** (RISE 사업단 수행과제, 2025.07–2026.02)

## 동작 구조

```
버튼 입력 → Picamera2 캡처 → YOLOv8n 로컬 탐지 → Gemini 2.0 Flash 장면 해석 → Google Cloud TTS → 음성 출력
```

로컬 탐지(YOLO)와 클라우드 해석(Gemini)의 역할을 나눴습니다. YOLO는 기기에서 "무엇이 어디에" 있는지를 빠르게 잡고, Gemini는 그 결과와 원본 이미지를 함께 받아 사람이 알아들을 문장을 만듭니다. 탐지만으로는 맥락이 없고, 클라우드만 쓰면 느리고 비용도 듭니다. 둘로 나눈 게 이 프로젝트의 핵심 설계입니다.

## 버튼 입력 처리

하나의 버튼으로 두 모드를 구분합니다. `BOARD` 핀 11번을 폴링하면서, 버튼이 떨어진 시점부터 `0.5`초 안에 다시 눌리면 더블클릭(모드 2)으로, 아니면 싱글클릭(모드 1)으로 판단합니다.

```python
if now - last_click_time < 0.5:
    click_count = 2   # 더블클릭 → 주변 묘사
else:
    click_count = 1   # 싱글클릭 → 위험 경고
```

음성이 재생되는 도중 버튼을 누르면 새 요청으로 처리하지 않고 재생을 즉시 중단합니다. 안내가 길게 이어질 때 바로 끊고 다음 상황을 들을 수 있도록 한 처리입니다.

## 폴백 흐름

보조기기가 침묵하는 것은 늦은 안내보다 위험하다고 보고, 2단으로 처리를 나눴습니다.

1. **네트워크 없음** → YOLO 로컬 탐지 결과만으로 "전방에 OO가 있습니다" 형태의 문장을 즉시 생성
2. **네트워크 있음, Gemini 호출 실패** → 역시 YOLO 탐지 결과로 되돌아가 문장을 생성
3. **정상** → YOLO 탐지 결과 + 원본 이미지를 Gemini에 함께 전달해 자연스러운 한국어 문장을 받음

## 탐지 대상

사람, 자전거, 자동차, 오토바이, 버스, 트럭, 신호등, 소화전, 벤치, 의자 — 보행 중 실제로 마주치는 대상 10종(COCO 클래스 기준)으로 좁혀 추론 속도를 확보했습니다.

## 프롬프트 설계

모드별로 다른 지시문을 Gemini에 전달합니다.

- **모드 1 (경고)**: YOLO 탐지 결과를 함께 전달하고, 탐지된 게 없어도 이미지를 직접 보고 판단하도록 지시. 결과는 한 문장, 한국어로만 제한.
- **모드 2 (묘사)**: 같은 입력에 "장면을 3문장으로 묘사하라"는 지시를 추가해, 분위기와 주변 상황까지 설명하도록 유도.

두 모드 모두 "영어 금지, 한국어로만 응답"을 명시해 TTS로 바로 넘길 수 있는 형태로 응답을 받습니다.

## 오디오 처리

- **SSML 무음 패딩** — 음성 합성 요청 앞에 `<break time="1000ms"/>`로 1초짜리 무음 구간을 넣습니다. 블루투스 스피커가 절전 모드에서 깨어나는 동안 첫 음절이 잘리는 문제가 있어서, 무음으로 스피커를 먼저 깨우고 본문을 재생하도록 바꿨습니다.
- **응답 캐시** — 합성한 문장을 MD5 해시로 파일명을 만들어 캐시합니다. 같은 문장은 네트워크 호출 없이 캐시된 음성 파일을 바로 재생합니다.
- **인터넷 상태 확인** — 매 요청 전 `8.8.8.8:53` 연결을 짧게 시도해 온라인 여부를 먼저 판단하고, 이에 따라 폴백 흐름을 선택합니다.

## 하드웨어

- Raspberry Pi (GPIO 버튼 1개, BOARD 핀 11, 풀업 입력)
- Picamera2 호환 카메라 (BGR888 우선 시도, 실패 시 RGB888로 자동 전환)
- 블루투스 스피커 (PulseAudio `paplay` 출력)

## 환경변수

`.env` 파일에 아래 값을 설정합니다.

| 변수 | 설명 |
| --- | --- |
| `GOOGLE_API_KEY` | Gemini API 키 |
| `GOOGLE_APPLICATION_CREDENTIALS` | Google Cloud 서비스 계정 JSON 파일 경로 |

TTS는 `google-cloud-texttospeech` 라이브러리가 `GOOGLE_APPLICATION_CREDENTIALS` 환경변수를 직접 읽으므로, 코드에서 별도로 전달하지 않아도 서비스 계정 키만 있으면 동작합니다.

## 설치 및 실행

```bash
pip install -r requirements.txt
python smart_cane.py
```

스피커 출력만 먼저 확인하려면:

```bash
python test_audio.py
```

## 파일 구조

```
smart_cane.py      # 메인 로직 — 버튼 입력, YOLO 탐지, Gemini 호출, TTS 재생
test_audio.py       # 블루투스 스피커 출력 확인용 스크립트
requirements.txt    # 의존성 목록
yolov8n.pt           # YOLOv8n 사전 학습 가중치
```

## 참고 사항

- `tts_cache` 캐시 경로가 개발 당시 환경 기준으로 하드코딩되어 있어, 다른 환경에서 실행할 때는 경로를 맞춰 줘야 합니다.
- 실행 환경(라즈베리파이)에 종속된 패키지(`RPi.GPIO`, `picamera2`)가 포함돼 있어, 일반 PC에서는 그대로 실행되지 않습니다.
